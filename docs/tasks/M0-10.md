## Otsused ja liidesed
- **Kihid:** `storage` ei sõltu `tauri` crate'ist (testitav puhta Rustina). `ipc.rs` on õhuke kiht `#[tauri::command]` → `storage`.
- **Käsud:**
  - `project_create(path, project_id, doc_json) -> OpenedProjectDto`: `project_id` annab TS (kutsuja loob id). Fail kirjutatakse kõigepealt `<path>.tmp`-ks ja nimetatakse siis ümber. Olemasoleva faili ülekirjutamise kinnitab kasutaja salvestusdialoogis enne käsku.
  - `project_open(path) -> OpenedProjectDto`.
  - `project_save(session, base_rev, rev, doc_json, journal: Vec<JournalDto>)`.
  - `project_save_view(session, view_json)`: kirjutab ainult `view` rea, `rev` ei muutu.
  - `project_close(session)`: suleb ühenduse ja vabastab luku.
- **DTO-d (ts-rs):**
  - `OpenedProjectDto { session, project_id, path, doc_json, view_json: Option<String>, format_version: u32, read_only: bool }`;
  - `JournalDto { at, kind, command_id, request_id: Option<String>, source, summary }`;
  - `StorageErrorDto { reason, actual_rev: Option<i64> }`, kus `reason` on üks väärtustest `disk_full`, `read_only`, `missing`, `locked`, `not_project`, `too_new`, `stale_rev`, `unknown`. `stale_rev` muudetakse TS-is `StorageError('unknown', actualRev)`-iks ülesandes 12.
- **Sessioon:** Rust loob juhusliku tunnuse ja hoiab `Mutex<HashMap<session, ProjectDb>>`. Tundmatu tunnus annab vea `unknown`.
- **`meta` võtmed:** `format_version`, `app_version`, `created_at`, `project_id`, `copied_from_project_id`, `media_dirty`.
- **Avamine järjekorras:**
  1. Fail puudub → `missing`.
  2. Esimesed 16 baiti pole `SQLite format 3\0` → `not_project`. Sellisel juhul SQLite'iga **ei** avata.
  3. Faili atribuut on kirjutuskaitstud → ava kirjutuskaitstuna ja tagasta `read_only: true` (see ei ole viga). Kirjutuskaitstud failis migratsiooni ega koristust ei tehta.
  4. Muidu ava ja sea `PRAGMA journal_mode=DELETE; synchronous=FULL; foreign_keys=ON; locking_mode=EXCLUSIVE;`, seejärel kohe `BEGIN EXCLUSIVE; COMMIT;`. `SQLITE_BUSY` või `SQLITE_LOCKED` → `locked`.
  5. Puudub `meta` tabel või `format_version` → `not_project`. Faili sisu ja muutmisaeg jäävad samaks.
- **Salvestus:** üks tehing: `UPDATE document SET json=?, rev=?, updated_at=? WHERE id=1 AND rev=?base_rev`.
  - Kui ridu muutus 0, tagasta `stale_rev` koos faili tegeliku `rev`-iga.
  - Logiread lisatakse samas tehingus.
  - `updated_at` on Rusti UTC aeg ISO 8601 kujul.
- **Veakoodide vastavus:** `SQLITE_FULL` → `disk_full`; `SQLITE_READONLY` või õiguste viga → `read_only`; `NotFound` → `missing`; `BUSY`/`LOCKED` → `locked`; muu → `unknown`.
