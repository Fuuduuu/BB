## Otsused ja liidesed
- **`RecentProject`** liigub `@pcbk/contracts`-i (adapterid ja UI impordivad sealt): `{ path; projectId; name; device?; updatedAt; missing? }`. `updatedAt` on kaardil näidatav aeg.
- **`AppHost`** (`@pcbk/contracts`):
  ```ts
  export interface AppHost {
    readonly kind: 'web' | 'desktop';
    recents(): Promise<RecentProject[]>;
    removeRecent(path: string): Promise<void>;
    listOpenable?(): Promise<RecentProject[]>;        // veeb: brauseri projektid; töölaual puudub
    pickProjectFile?(): Promise<string | null>;       // töölaud: avamisdialoog; veebis puudub
    pickSavePath?(suggestedName: string): Promise<string | null>; // töölaud: „Salvesta mujale…“; veebis puudub
    onCloseRequested(handler: () => Promise<boolean>): Unsubscribe; // true = võib sulgeda
    onOpenPath(handler: (path: string) => void): Unsubscribe;       // veebis no-op
    closeNow(): void;                                  // veeb: lehe uuestilaadimine; töölaud: aken kinni
    reload(): void;
    saveDiagnostics(summary: string): Promise<void>;
  }
  ```
  Kui teostus vajab väikest lisameetodit, lisa see ja nimeta üleandmises. Puuduv valikuline meetod tähendab UI-s keelatud nuppu koos olemasoleva selgitusega.
- **Jagatud töölaud** `packages/ui/src/app/Workbench.tsx` saab props'ideks `host: AppHost` ja `uiModules` (koostekoht annab need). Mootorit ja teenust loeb see `@pcbk/client` hook'idega. `ui` ei impordi `adapters`-it ega mootorit (sõltuvusreeglid kehtivad edasi).
- **Moodulite loend ühes kohas:** `packages/features/engine.ts` ekspordib `engineFeatures` ja `RESERVED_FIELDS_M0`; `packages/features/ui.ts` ekspordib `uiFeatures(ids, onHome)`. Mõlemad rakendused impordivad need ja ei hoia oma koopiat. Uus moodul tähendab ühte rida kummaski failis.
- **`RESERVED_FIELDS_M0` on selgesõnaline loend,** mitte „kõik, millel omanikku pole“: `photos`, `activePhotoId`, `scale`, `junctions`, `connections`, `netLabels`, `roles`, `measurements`, `measureSettings`, `repairs`, `areas`, `dimensions`, `outline`, `textNotes`, `guide`.
- **Uus sõltuvusreegel `features-registry-apps-only`:** `packages/features/engine.ts` ja `ui.ts` võib importida ainult `apps/*`. Muidu saaks mooduli UI nende kaudu mootorini.
- **`web-host.ts`** teostab `AppHost`-i olemasoleva veebihoidla ja `beforeunload`-iga. Käitumine jääb samaks.
- **`DeepReadonly` toetab ka `Map`-i ja `Set`-i** (Gemini ülevaatusest): `Map<K,V>` muutub kujuks `ReadonlyMap<DeepReadonly<K>, DeepReadonly<V>>` ja `Set<T>` kujuks `ReadonlySet<DeepReadonly<T>>`. Lisa `contracts.test-d.ts`-i kontroll, et `.set()` ja `.add()` ei kompileeru. Reegel jääb samaks: `Derived` ja dokument sisaldavad ainult tavaobjekte ja massiive, sest mootori `sealTree` lükkab teised prototüübid tagasi. Tüübitugi on lisakaitse.
