# M0-14 · Taasta varukoopiast avalehelt

**Olek:** vastu võetud `e75e7ac` · **Haru:** m0 · **Alus:** `0e6207c` · **Plaan:** [07 › M0](../07-teekaart.md#m0--vundament-ja-esimene-komponent) tingimus „Taastamine avalehelt uude faili on läbi proovitud“

## Eesmärk
Töölaual saab avalehe projektikaardilt valida „Taasta varukoopiast…“, näha selle projekti varukoopiaid, valida ühe, anda uue faili tee ja saada taastatud projekt avatuna. Praegu on nupp alati keelatud ja `ProjectService.backups()` töötab ainult avatud projekti jaoks. Rust (`project_backups`, `project_restore`) ja `storage-tauri` on valmis ning jäävad muutmata.

## Otsused ja liidesed
- **Leping (arhitekt otsustas):** `ProjectService.backups(req?: { projectId: string })`.
  - Ilma `req`-ita: nagu praegu, aktiivse projekti koopiad; aktiivse projekti puudumisel `stale_session`.
  - `projectId`-ga: selle projekti koopiad, **ka siis kui projekti pole avatud**. See on avalehe kasutusjuht.
  - Tüüp `BackupsReq = { projectId: string }` ekspordib `contracts`.
- **`StartScreen`:** uus valikuline prop `onRestore?(project: RecentProjectCard): void`.
  - Kui `onRestore` puudub (veeb): nupp jääb keelatuks tekstiga `restoreUnavailable`, nagu praegu.
  - Kui olemas: nupp on lubatud, ka kaardil, mille fail puudub (`missing`). See ongi peamine taastamise juht.
- **`RestoreDialog`** (`Dialog`-komponendiga, nagu `NewBoardDialog`): avaneb kaardi nupust, laeb `projects.backups({ projectId: project.projectId })`.
  - Laadimise ajal tekst `restoreLoading`; tühi loend `restoreNone`; viga `restoreFailed` (ei sulge dialoogi, võimaldab uuesti).
  - Loend uuemad enne. Rida näitab kuupäeva ja kellaaega `HH:MM` (kohalik aeg, sekunditeta) ja silti (`full` → „Täiskoopia“, `doc` → „Muudatuste koopia“). Valik on raadionupp; vaikimisi uusim. `Taasta` nupp lubatud alles pärast valikut.
- **Voog „Taasta“:** `host.pickSavePath?.(`${project.name} (taastatud)`)`; kui `null` (tühistatud), ei tehta midagi. Muidu `projects.restore({ backup: file, dest })`.
  - Õnnestumisel avaneb taastatud projekt töölauas nagu `open` tulemus (sama kood, mis avamisel: vaade, valik lähtestub, viimaste loend uueneb).
  - Veal (`exists`, `locked`, `unknown` jt) näita `restoreFailed` dialoogis ja jää avalehele.
- **Tekstid `et.ts` `project` all:** `restoreTitle: 'Taasta varukoopiast'`, `restoreLoading: 'Varukoopiaid laaditakse…'`, `restoreNone: 'Selle projekti varukoopiaid ei leitud.'`, `restoreFailed: 'Taastamine ebaõnnestus. Algne projekt on muutmata.'`, `restoreFull: 'Täiskoopia'`, `restoreDoc: 'Muudatuste koopia'`, `restoreConfirm: 'Taasta'`. `restoreUnavailable` ja `restore` jäävad.
- Taastamine **ei kirjuta algset faili üle**: sihtfail on alati uus (Rust kontrollib). Ära lisa ülekirjutamisvalikut.

## Tõend
- Testid (nimega):
  - engine: `backups with projectId lists without an open project`; `backups without request still needs an open project`;
  - UI: `restore button is disabled without host support`; `restore dialog lists backups newest first and restores into a chosen file`; `restore cancelled in save dialog does nothing`; `restore failure keeps the start screen and shows the message`; `missing project card can still be restored`.
- Käsud: `pnpm check`, `pnpm format:check`, `pnpm e2e` (8/8), `pnpm api:check`, `cargo test --locked` (46/46, muutmata).
- **Suitsukontroll päris aknas** (`pnpm tauri dev`), kirjuta tulemus üleandmisse; mida ise ei saanud, märgi kasutaja vastuvõtuks:
  1. Loo projekt, lisa komponent, sulge. Ava uuesti (tekib päevane täiskoopia).
  2. Avalehel kaardil „Taasta varukoopiast…“ → loend sisaldab vähemalt ühe koopia → vali, anna uus fail → projekt avaneb, komponent on olemas.
  3. Kustuta algne `.pcbk` fail (kopeeri enne eraldi!) → kaart on „Faili ei leitud“ → taastamine toimib sellegipoolest.
