## Otsused ja liidesed

```ts
export interface PadGeom { id: string; x: number; y: number; w: number; h: number; shape: 'rect' | 'circle'; through: boolean }
export interface FootprintGeom { pads: PadGeom[]; body: { w: number; h: number; pin1?: Vec2 } }
export interface FootprintParams { [k: string]: string | number }
export interface FootprintDef { key: string; name: string; defaults: FootprintParams; gen(p: FootprintParams): FootprintGeom | undefined }
export const FOOTPRINTS: readonly FootprintDef[];
export function footprintGeometry(key: string, params: FootprintParams): FootprintGeom | undefined;
export function footprintPinIds(key: string, params: FootprintParams): string[] | undefined;
```

- Kasuta olemasolevat `Vec2` tüüpi `{ x: number; y: number }`. Päritolu on kere keskel, x kasvab paremale ja y alla. Padjandi `x/y` on keskpunkt. Ümarda arvutatud mõõdud ja asukohad prototüübi viisil `Math.round(value * 1000) / 1000`.
- Registri järjekord ja tehnilised nimed on `chip` / `Chip`, `sot23` / `SOT-23`, `soic` / `SOIC`, `to220` / `TO-220`, `header1` / `1×N`, `area` / `Area`. Padjandite ID-d on stringid `"1"`, `"2"` jne numbrilises järjekorras. `footprintPinIds` tagastab samas järjekorras ID-d, `area` puhul `[]`.
- `footprintGeometry` täidab puuduvad parameetrid vaikimisi ja annab täieliku komplekti `gen`-ile. `gen` valideerib selle komplekti. Tundmatu võti, üleliigne või vigane parameeter annab mõlemas avalikus päringus `undefined`. Arvulistele parameetritele sobivad ka mittetühjad punktiga kümnendarvu stringid. `chip.size` on täpne string. Kehtiv päring tagastab värske geomeetria ja jätab sisendi muutmata.
- **`chip`** vaikimisi `size: '0805'`. Tabeli veerud on padjandi kaugus keskelt `c`, padjandi `w/h` ja kere `w/h`. Jalg 1 on `(-c, 0)`, jalg 2 `(c, 0)`. Mõlemad on `rect`, `through: false`.

| `size` | `c` | Padjandi `w` | Padjandi `h` | Kere `w` | Kere `h` |
|---|---:|---:|---:|---:|---:|
| `0402` | 0.5 | 0.6 | 0.6 | 1 | 0.5 |
| `0603` | 0.8 | 0.8 | 0.95 | 1.6 | 0.8 |
| `0805` | 1 | 1 | 1.35 | 2 | 1.25 |
| `1206` | 1.5 | 1.15 | 1.8 | 3.2 | 1.6 |
| `1210` | 1.5 | 1.15 | 2.7 | 3.2 | 2.5 |
| `2010` | 2.4 | 1.3 | 2.6 | 5 | 2.5 |
| `2512` | 2.95 | 1.5 | 3.4 | 6.3 | 3.2 |

- **`sot23`** vaikimisi `pins: 3`, lubatud `3`, `5`, `6`. Padjandid on `0.6 × 0.8`, `rect`, `through: false`. ID järjekorras on 3 jalaga `(-0.95, 1)`, `(0.95, 1)`, `(0, -1)`. 5 ja 6 jalaga on esimesed kolm `x = -0.95, 0, 0.95` ja `y = 1.1`. Ülejäänud `y = -1.1`, 5 jalaga `x = 0.95, -0.95`, 6 jalaga `x = 0.95, 0, -0.95`. Kere `w = 2.9`, `h = 1.3` (3 jalga) või `1.6`. Märk `pin1 = (-1.05, h/2 - 0.35)`.
- **`soic`** vaikimisi `pins: 8`, `body: 3.9`. Lubatud `pins` on `8, 14, 16, 20, 24, 28`, `body` on `3.9` või `7.5`. Olgu `n = pins/2`, `c = body/2 + 1.55/2 + 0.05`, `y0 = -(n-1)*1.27/2`. Iga `i = 0…n-1` korral on vasakul ID `i+1`, paremal ID `pins-i`, asukohad `(-c, y0+i*1.27)` ja `(c, y0+i*1.27)`. Padjandid `1.55 × 0.6`, `rect`, `through: false`. Kere `w = body`, `h = n*1.27 - 0.2`. Märk `pin1 = (-w/2+0.6, -h/2+0.6)`.
- **`to220`** parameetriteta. Kere `10.2 × 4.6`. Prototüübis on kere ülaserv `y = -3.4` ja padjandid `y = 0`. Kere keskpunkti nihutamisel päritolusse on padjandite `y = 1.1` ning `x = -2.54, 0, 2.54`. Padjandid `1.9 × 2.6`, `through: true`. Tüübis esitatakse kõik kolm `rect`-ina, säilitades prototüübi ovaalsete padjandite mõõdud.
- **`header1`** vaikimisi `pins: 4`, `pitch: 2.54`. Lubatud täisarv `pins` on `1…40`, `pitch` on `1.27`, `2` või `2.54`. Nullist algava `i` padjandi asukoht on `((i-(pins-1)/2)*pitch, 0)`, `w = h = pitch*0.68`, esimene `rect`, ülejäänud `circle`, kõik `through: true`. Kere `w = pins*pitch`, `h = pitch`.
- **`area`** vaikimisi `w: 8`, `h: 10`. Mõlemad mõõdud peavad olema lõplikud positiivsed arvud. Tagasta kere nende mõõtudega ning `pads: []`. `chip`, `to220`, `header1` ja `area` jätavad `body.pin1` välja.
