## Otsused ja liidesed
```ts
export type ReadingMode = 'voltage';                        // M3 laiendab: 'resistance' | 'diode'
export function parseReading(text: string, mode: ReadingMode): { value: number } | null;
export function formatReading(reading: { value: number }, mode: ReadingMode): string;
export interface PinReading { measurementId: string; mode: 'voltage'; value: number; takenAt: string }
export interface PinReadingSource {
  readonly components: readonly { readonly id: string; readonly pins: readonly Readonly<Pick<Pin, 'id' | 'uid'>>[] }[];
  readonly measurements: readonly Readonly<Measurement>[];
}
export function pinReadings(doc: PinReadingSource): Record<string, PinReading>;   // võti = punase sondi jala uid
```
- **`mode` argument on kohe olemas** (04 allkiri `parseReading(text, mode)`). Nii ei pea M3 allkirja muutma, vaid laiendab režiime ja tagastust.
- **Lugemise reeglid (pinge):**
  - Tühikud eemaldatakse kõikjalt.
  - Koma ja punkt on samaväärsed kümnendmärgid. Rohkem kui üks kümnendmärk (`1,2,3`, `1.234,5`) annab `null`.
  - Lubatud on märk `+` või `-` alguses; negatiivne pinge on lubatud (sondid võivad olla vahetuses).
  - Kordaja `m` (10⁻³), `k` (10³) või `M` (10⁶) võib olla arvu lõpus (`5m`, `4.7k`) või kümnendmärgi asemel (`4k7` = 4700, `3m3` = 0,0033).
  - Ühik `V` (suur- või väiketähega) on valikuline ja tuleb kõige lõpus: `4,98V`, `5 mV`, `3m3 V`.
  - Muu ühik (`Ω`, `A`, `Hz`, `kΩ`), `OL`, tühi tekst, ainult märk või kordaja, mittelõplik tulemus (`1e999`) ja muud sümbolid annavad `null`. Teaduslikku kuju (`1e3`) ei toetata.
- **Vormindus (pinge):** kümnendkoma.
  - |v| ≥ 1 → kuni 3 kümnendkohta, lõpunullid eemaldatud, ` V` lõpus: `4,98 V`, `12 V`, `-5 V`.
  - 0 < |v| < 1 → millivoltides, kuni 2 kümnendkohta: `0,0033` → `3,3 mV`, `0,5` → `500 mV`.
  - 0 → `0 V`.
- **`pinReadings` (kehtiv kirje):**
  - `mode === 'voltage'`, `staleByRepairId` puudub, `value` on lõplik arv;
  - `at` viitab olemasolevale komponendile, selle jalale sama `id`-ga ja sama `uid`-ga;
  - kui `ref` on olemas, kehtib sama tingimus ka sellele.
  - Iga punase sondi `uid` kohta valitakse suurima `takenAt`-iga kirje (ISO UTC; võrdle `Date.parse`-iga). Võrdse aja korral võidab dokumendis hilisem kirje.
  - Tulemus on tavaline objekt (mitte `Map`), sest mootor külmutab tuletised ja lubab ainult tavaobjekte. Sisendit ei muudeta.
