## Otsused ja liidesed
- **`COMPONENT_LIBRARY`** (contract): `LibraryEntry = { id; kind: ComponentKind; footprint: string; params: FootprintParams; kw: string }`.
  - Nime ja tähise eesliidet kirjel **pole**: kasutajale nähtav nimi tuleb `et.ts`-ist id järgi (kaart M1-1-8) ja eesliide tuleb `refPrefix(kind)`-ist.
  - Kirjed järjekorras (`kw` prototüübist):

    | id | kind | footprint | params | kw |
    |---|---|---|---|---|
    | `r_smd` | `resistor` | `chip` | `{ size: '0805' }` | `resistor chip` |
    | `c_smd` | `capacitor` | `chip` | `{ size: '0805' }` | `capacitor mlcc` |
    | `sot23` | `npn` | `sot23` | `{ pins: 3 }` | `transistor mosfet` |
    | `soic` | `ic` | `soic` | `{ pins: 8, body: 3.9 }` | `so ic` |
    | `to220` | `regulator` | `to220` | `{}` | `regulator mosfet` |
    | `hdr1` | `connector` | `header1` | `{ pins: 4, pitch: 2.54 }` | `header pin` |
    | `unknown` | `other` | `area` | `{ w: 8, h: 10 }` | `unknown generic custom` |
  - `kw` väärtused on ülal täpselt antud (arhitekti vastus ehitaja küsimusele 2026-11-10); prototüüpi pole vaja lugeda. Eestikeelne otsing käib hiljem `et.ts` nime järgi (kaart M1-1-8).
  - Väärtus ja märgistus jäävad tühjaks (prototüübi `10k`/`100n` vaikeväärtusi **ei** võeta üle).
- **`BoardInput = { footprint: string; params?: FootprintParams; center: Vec2; rotationDeg?: number; side?: Side }`**.
  - Salvestatakse täielik parameetrikomplekt (vaikeväärtused liidetud), `rotationDeg` normaliseeritud vahemikku `0 ≤ x < 360`, `side` vaikimisi `'top'`, `scaleX = scaleY = 1`, `customPads = {}`.
  - Tundmatu korpus või vigased parameetrid annavad `validation` (`invalid_footprint`). Mittelõplik `center` või nurk annab `validation`.
- **`components.add` saab valikulise `board`-i.** Tavalise korpuse puhul peab jalgade ID-de hulk olema täpselt sama mis `footprintPinIds`; muidu tuleb `validation` (`footprint_pins_mismatch`). Korpus `area` lubab mis tahes käsitsi jalgu. M0 kutse ilma `board`-ita jääb samaks.
- **`makePlacedComponent(ids, entry, params, center): AddComponentParams`**: loob `cmp_` id ja iga jala `pin_` uid generaatori järjekorras. Tähise jätab tühjaks, nii et käsk annab `nextRef`-iga järgmise.
- **Uued käsud** (zod-skeemid contract'is, mooduli omand `components`):
  - `components.placeOnBoard { id; board: BoardInput }`: ainult paigutamata komponendile, muidu `validation` (`already_placed`). Jalad seotakse ID järgi; olemasolevate jalgade järjekord ja `uid` säilivad.
  - `components.removeFromBoard { id }`: kustutab `board`-i, jalad ja mõõtmised jäävad. Paigutamata komponendil on see tühi käsk (`rev` ei muutu).
  - `components.rotate { id; deltaDeg }`: tulemus normaliseeritud `0 ≤ x < 360`.
  - `components.flipSide { id }`.
  - `components.setLabelOffset { id; offset: Vec2 | null }`: `null` eemaldab nihke.
  - `rotate`, `flipSide` ja `setLabelOffset` paigutamata komponendile annavad `validation` (`component_not_placed`). Puuduv komponent annab `not_found`.
- **`items.translate { items: { kind: 'component'; id: string }[]; dx: number; dy: number }`** on mootori tuumas (`items.ts`, `alsoWrites: ['components']`, nagu `items.delete`).
  - Korduvad id-d arvestatakse üks kord.
  - Paigutamata komponent annab `validation` (`component_not_placed`), puuduv `not_found`. Mittelõplik nihe annab `validation`.
  - `dx = dy = 0` on tühi käsk ilma ajaloosammuta.
- **Vormindusparandus (M1-1-3 ülevaatusest):** `formatReading` valib ühiku pärast ümardamist, nii et `0.999999` annab `1 V`, mitte `1000 mV`.
