## Otsused ja liidesed
- **Contract** (`features/measurements/contract.ts`):
  - `AddMeasurementParams = { id; mode: 'voltage'; at: MeasuredPin; ref?: MeasuredPin; value: number; power: 'on' | 'off' | 'unknown'; takenAt: string; note?: string }` ja `RemoveMeasurementParams = { id }`, zod-skeemidega;
  - lepingut **ei** kasutata domeeni käituskoodi edasiandmiseks. UI impordib lugemise ja vorminduse otse lubatud alateelt (vt „UI ja domeen“ allpool).
- **`measurements.add`:**
  - `value` on lõplik arv, `takenAt` ISO UTC, `id` kutsujalt (`msr_`);
  - `at` ja olemasolev `ref` peavad viitama olemasolevale komponendile, selle jalale ja sama `uid`-ga; muidu `validation` (`pin_not_active`);
  - `ref` ei tohi olla sama jalg mis `at` (`same_probe_twice`);
  - salvestab `atLabel` ja `refLabel` kujul `"<tähis>.<jala id>"` (näiteks `U1.8`), `source: 'manual'`;
  - vana salvestusvormingu kirjed jäävad loetavaks (skeemi ei kitsendata).
- **`measurements.remove`:** puuduv id annab `not_found`; kustutamine on tagasivõetav.
- **Moodul:** `{ id: 'measurements', dependsOn: ['components'], owns: ['measurements'], commands, derive }`. `packages/features/engine.ts` registreerib selle. Väli `measurements` eemaldatakse reserveeritutest; `measureSettings` jääb reserveerituks M3-ni. Nimeta konstant ümber `RESERVED_FIELDS`-iks (kommentaar: „veel ehitamata moodulite väljad“), sest see ei ole enam M0 loend.
- **`Derived` on laiendatav nagu `CommandMap`** (Fable ülevaatus 2026-11-10, arhitekt kinnitas). `@pcbk/contracts` jätab tuuma võtmed `unplacedBoard` ja `unplacedSchematic`; mõõtmismoodul lisab `pinReadings: Record<string, PinReading>` oma `contract.ts`-is mooduliaugmentatsiooniga (võti on punase sondi jala `uid`, tüüp domeenist ainult tüübina). Nii ei muuda järgmised moodulid enam lepingupaketti.
- **Tuletiste üldistus:**
  - `DeriveSpec<K extends keyof Derived> = { key: K; inputs: DocKey[]; schema: z.ZodType<Derived[K]>; initial: Derived[K]; run(doc, derived): Derived[K] }`. Moodul annab skeemi (`pinReadings` puhul domeeni `PinReadingsSchema`, mille lisad `measure/`-i) ja algväärtuse (`{}`).
  - Mootor alustab tuuma vaikeväärtustest ja registreeritud specide `initial`-ist (tühi hetktõmmis).
  - **Meelespidamine (03 §7.4):** spec arvutatakse uuesti ainult siis, kui mõne `inputs` välja viide muutus võrreldes eelmise hetktõmmisega (Immeri struktuurne jagamine); muidu kasutatakse eelmist väärtust. `pinReadings` sisendid on `['components', 'measurements']`.
  - Iga spec valideeritakse oma skeemiga. Vigane tulemus peatab käsu enne ajaloo ja hetktõmmise avaldamist (`validation`).
  - Registris jääb korduva võtme keeld.
- **UI ja domeen** (Fable ülevaatus): reegel `ui-domain-types-or-geometry` muutub lubatud kaustade loendiks: UI võib domeenist käituskoodi importida ainult `geometry/`, `footprints/` ja `measure/reading.ts` failidest. `measure/pin-readings.ts` (tuletise arvutus) jääb UI-le keelatuks. Testandmetes: UI import `measure/reading` läbib, `measure/pin-readings` kukub.
- **`dependsOn` kontroll** (`tooling/feature-deps.test.ts`, jookseb `pnpm check`-iga):
  - dependency-cruiser'i API leiab tootmiskoodi impordid kujul `packages/features/X/**` → `packages/features/Y/**` (X ≠ Y), sh tüübiimpordid;
  - iga serva korral peab `engineFeatures`-is mooduli `X` `dependsOn` sisaldama `Y`-t (kausta nimi = mooduli id);
  - testandmetes peab deklareerimata import kukkuma ja deklareeritud import läbima;
  - olemasolev privaatfailide keeld jääb.
