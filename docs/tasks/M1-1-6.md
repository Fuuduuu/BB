## Otsused ja liidesed
- **Valik** (kesta `SessionStore`): `Selection = { items: SelectionItem[] }`, `SelectionItem = { kind: string; id: string; componentId?: string }`. Tühi valik on `{ items: [] }`. Jala valik: `{ kind: 'pin', id: <pin id>, componentId }`. M1.1 kasutab ühte elementi; `Shift`+klõps ja raamvalik tulevad M2.1-s ilma kuju muutmata. Migreeri olemasolev kasutus (komponentide loend ja omadused).
- **Kontekstisektsioon** kehtib, kui valik pole tühi ja **kõik** valitud elemendid on `appliesTo` tüüpi (`appliesTo: string[]`).
- **Seansi olek:** kest hoiab ainult valikut, aktiivset tööriista (`toolId`) ja üht üldist eelvaatepesa `preview: { owner: string; data: unknown } | null`. Liigutamise eelvaade on `owner: 'select'`, `data: TranslatePreviewData = { items: SelectionItem[]; dx: number; dy: number }` (tüüp eksporditakse `canvas/`-st, et kihid saaks seda lugeda). `UiModule` saab `onSessionReset?(): void`, mille kest kutsub projekti vahetusel (mooduli oma hoidlad, otsus 11).
- **Tabamus (üldine):** `HitItem = { kind: string; id: string; componentId?: string; shape: HitShape; priority?: number; data?: unknown }`, `HitShape = { type: 'point'; at: Vec2; r: number } | { type: 'segment'; a: Vec2; b: Vec2; width: number } | { type: 'area'; polygon: Vec2[] }` (maailma pikslites). `createHitIndex(items, cellPx = 32)` ruudustikuga; `query(world, zoom)` arvestab minimaalset ekraaniraadiust 6 px. Võitja: kõigepealt kõrgem `priority`, siis lähim kaugus kujuni (punkt: keskpunktist; lõik: lõigust; ala: 0 sees). Indeks ehitatakse uuesti ainult `rev`-i muutusel.
- **Kihid ja tööriistad:** `LayerSpec = { id; z; render(props: { snapshot; preview; zoom }): ReactNode; hits?(snapshot): HitItem[] }`, `ToolSpec` ja `CanvasTool` plaani järgi. `UiModule` saab `canvasLayers?` ja `tools?`; `UiRegistry` koondab need (id-d unikaalsed, kihid `z` järjekorras).
- **`Canvas`** saab props'ideks `layers`, `tools`, `sceneTransform` (M1.1-s `'none'`; 8 väärtust 04 `PhotoRef.transform` järgi) ja `view` (`{ zoom; pan }` + muutuse kuulaja). Koordinaadistik ja teisendus on parameetrid, mitte plaadi eeldus, et M2.3 skeem saaks sama komponenti kasutada.
- **`SceneText`**: tekstielement, mis liigub koos stseeniga, aga joonistatakse alati loetavalt (vastuteisendus pöörde ja peegelduse suhtes).
- **Valikutööriist (`V`):** klõps valib tabamuse (jala või komponendi), tühi klõps tühjendab; lohistamine alates 3 px liigutab valitud komponente eelvaatena; hiire vabastamisel üks `items.translate`. `Esc`, `pointercancel`, tööriista vahetus ja projekti vahetus kustutavad eelvaate jäljetult. Nooled nihutavad 1 px, `Shift`+nool 10 px (üks käsk vajutuse kohta). Sisestusväljas lõuendi klahvid ei käivitu.
- **Vaade:** nihe keskmise nupuga või tühik + lohistamine (`H` tööriist); suum rullikuga kursori ümber; ekraan → maailm `getScreenCTM().inverse()` kaudu. Suum ja nihe rakenduvad imperatiivselt ühele `<g transform>`-ile, kihte ei renderdata uuesti.
- **`ViewState.boardView?: { zoom: number; pan: Vec2 }`** (vaikimisi `zoom: 1`, `pan: {0,0}`). Leebe parser: vigane või puuduv `boardView` asendub vaikeväärtusega, ülejäänud väljad säilivad. Ainult vaate muutus ei muuda `rev`-i.

## Arhitekti ülevaatus (2026-11-10)
Lõuend järgib otsust 11: üldine tabamus (punkt, lõik, ala, prioriteet, 6 px ekraanimiinimum), mitmikvaliku kuju, kesta seansiolekus ainult valik, tööriist ja eelvaatepesa, moodulite lähtestuskonks, kihid ja tööriistad registrist, stseeni teisendus ja `SceneText`. `boardView` püsib ilma `rev`-i muutmata. Kontrollid: `pnpm check` 658/658 (0 sõltuvusrikkumist), `pnpm format:check`, `pnpm e2e` 8/8 (M0 testis lisandus ainult oodatud `boardView` vaikeväärtus). **Vajab üht parandust:**

1. **Valimata komponenti ei saa ühe liigutusega lohistada.** `SelectTool` alustab liigutamist ainult siis, kui vajutus on juba valitud komponendil; valimata komponendi lohistamine ei tee midagi ega muuda valikut. Kasutaja peab praegu enne klõpsama ja siis lohistama. Paranda nii: vajutus valimata komponendil valib selle kohe (asendab valiku) ja sama liigutus võib seda lohistada; vajutus juba valitud komponendil jätab valiku samaks ja lohistab kõiki valitud komponente. Jalal vajutus valib jala ainult klõpsu korral (lohistamine jala pealt liigutab selle komponenti). Testid: `drag_unselected_component_selects_and_moves_in_one_gesture`, `drag_from_pin_moves_its_component`.

Pärast parandust muuda olek `ülevaatusel` ja lisa üleandmisse üks rida.
