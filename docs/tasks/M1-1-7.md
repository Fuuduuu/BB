## Eesmärk
Plaadile paigutatud komponendid paistavad lõuendil kere, jalgade ja tähisega. Klõps jalal valib jala, klõps kerel komponendi, kere lohistamine liigutab komponenti (M1-1-6 valikutööriist). Tähise silti saab lohistada eraldi, komponent ei liigu. Kihid uuendavad detailsust (LOD) pärast suumi lõppu.

## Otsused ja liidesed
- **Kihid** (`COMPONENTS_LAYERS: LayerSpec[]`, registreeritakse `createComponentsUi`-s): `components.bodies` z 30, `components.pins` z 50, `components.labels` z 60. Joonistatakse ainult komponendid, millel on `board`. Mõõtkava on `snapshot.doc.scale.pxPerMm`, mitte konstant.
- **Geomeetria:** kere `bodyOutline(board, pxPerMm)`, jalad `boardPads(board, pins.map(p => p.id), pxPerMm)`. **Jalg 1** on `boardPads` tulemuse esimene element; see joonistatakse ruuduna ka ümmarguse padjandi korral.
- **Jalg** (06): maailma raadius `r = max(radiusPx, 5 / zoom)` (ekraanil ≥ 10 px läbimõõt). Number nähtav, kui `r·zoom ≥ 7`, nimi (`pin.name`) lisaks, kui `r·zoom ≥ 14`. Halo 1,5 px `--halo`. Ühendamata: täiteta, kontuur 1,5 px `--ink-3`. NC (`pin.nc`): täiteta, kontuur 1 px ja väike rist. Valitud jalg: lisarõngas +2 px `--sel`.
- **Kere** (06): kontuur 1,4 px `--body`, täide `--body-fill`, halo 3,6 px `--halo` (halo joonistatakse enne kontuuri). Alumine pool (`side: 'bottom'`): katkendjoon. Valitud komponent: kontuur `--sel`. DNP: kere 40 % läbipaistvusega ja tähis läbikriipsutatud. Tuvastamata (`identified: false`): tähise järel väike „?“.
- **Joonte paksus** on ekraani pikslites: `vector-effect="non-scaling-stroke"`. Kriipsu muster arvesta samuti ekraanil.
- **Tähis ja väärtus:** teksti maailma suurus `1,6 mm · pxPerMm`; joonistatakse ainult, kui `suurus · zoom ≥ 8`. Ankur `center + (labelOffset ?? { x: 0, y: -(kere kõrgus px / 2 + 1 mm · pxPerMm) })`, väärtus (kui pole tühi) tähise all. Kasuta `SceneText`-i, `--f-mono`, `tabular-nums`. Silt ei pöördu koos komponendiga.
- **Valik kihis:** kiht loeb `useSessionStore`'ist valiku ja annab igale `ComponentShape`'ile ainult `selected: boolean` ja `selectedPinId: string | null`. `ComponentShape` ja `PinMarker` on `React.memo`; komponent renderdub ainult siis, kui muutub tema `Component` objekt, `pxPerMm`, valikuolek, LOD-suum või tema eelvaate nihe. Lohistamise eelvaade (`preview.owner === 'select'`, `TranslatePreviewData`) nihutab ainult eelvaates olevaid komponente `translate(dx dy)` abil.
- **Tabamus** (`hits`): jalg `{ kind: 'pin', id: pin.id, componentId, shape: { type: 'point', at, r: radiusPx }, priority: 2 }`, kere `{ kind: 'component', id, shape: { type: 'area', polygon: bodyOutline }, priority: 0 }`, nähtav tähis `{ kind: 'component-label', id, componentId: id, shape: { type: 'area', polygon: <sildi ristkülik> }, priority: 1, target: { kind: 'component', id }, drag: labelDrag }`.
- **Lõuendi laiendus (`HitItem`):** lisa valikulised `target?: SelectionItem` (mida klõps valib; vaikimisi `{ kind, id, componentId }`) ja `drag?: HitDrag`, kus `HitDrag = { owner: string; commit(delta: Vec2, api: ToolApi): void }`. `SelectTool`: kui vajutuse tabamusel on `drag`, siis valik vajutusel ei muutu; ≥ 3 px järel eelvaade `{ owner: drag.owner, data: { id: hit.id, dx, dy } }`; vabastamisel eelvaade kustub ja kutsutakse üks kord `drag.commit`. Klõps ilma lohistamiseta valib `target`. Katkestused nagu M1-1-6.
- **Sildi lohistamine:** `owner: 'components.label'`; `commit` kutsub `components.setLabelOffset({ id, offset: vana nihe + delta })`, kus vana nihe on `labelOffset` või ülal kirjeldatud vaikenihe. Komponendi `center` ei muutu.
- **LOD-suum (`Canvas`):** lõuend hoiab olekut `lodZoom`, mis võrdub `view.zoom`-iga 120 ms pärast viimast vaate muutust (`setTimeout` + `requestAnimationFrame`). `Layers` võrdlusfunktsioon arvestab `lodZoom`-i ja kihid saavad `zoom: lodZoom`. `LayerSpec.hits` saab teise argumendi: `hits?(snapshot, zoom: number)`; tabamusindeks ehitatakse uuesti `rev`-i, seansi, kihtide või `lodZoom`-i muutusel. Nii on tähise tabamus olemas ainult siis, kui tähis on nähtav. Nihutamine ilma suumi muutuseta kihte ega indeksit uuesti ei ehita.
- **`rev`-i muutus lohistamise ajal** (nt `Ctrl+Z`) katkestab aktiivse žesti nagu `Esc`: eelvaade kustub, käsku ei saadeta.
