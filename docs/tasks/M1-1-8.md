# M1-1-8 · Teek, paigutustööriist, loendid ja „Korpus ja asend“

**Olek:** vastu võetud `6efa841` · **Haru:** `codex/m1-1` · **Alus:** `3e794f9` + M1-1-6…7 (commitimata) · **Plaan:** [M1.1 ülesanne 8](../plans/M1-1-louend-ja-mootmine.md#ülesanne-8-teek-paigutamine-ja-plaadilpaigutamata-loendid)

## Eesmärk
Kasutaja valib teegist korpuse, klõpsab plaadil ja komponent on paigas ning valitud (üks `components.add` koos `board`-iga). Paigutamata komponendi saab paigutada sobiva korpusega. Valitud komponenti saab pöörata (`R`/`Shift+R`), teisele poolele viia (`F`) ja plaadilt eemaldada.

## Otsused ja liidesed
- **Vahekaardid** (`navigatorTabs`, järjekord): `library` „Teek“ (order 0), `components` „Plaadil“ (order 1, id jääb samaks, sest salvestatud vaade ja vaikimisi vahekaart on `components`), `unplaced` „Plaadile paigutamata“ (order 2, loendur sulgudes, kui > 0). M0 nupp **Lisa komponent** (olemasolev dialoog, loob paigutamata komponendi) liigub vahekaardile „Plaadile paigutamata“.
- **Arhitekti vastus ehitajale (2026-11-10):**
  - **`PanelSpec.count?(snapshot: Snapshot): number`.** Navigaator kuvab pealkirja järel `(n)`, kui tulemus on > 0. „Plaadile paigutamata“ kasutab `snapshot.derived.unplacedBoard.length`.
  - **Avalik alatee `@pcbk/domain/footprints`** → `./src/footprints/index.ts` (`packages/domain/package.json` `exports`). Sõltuvusreegel lubab UI-l `footprints/` kausta juba praegu kasutada. UI võtab `footprintPinIds` ja vajadusel `FOOTPRINTS` sealt.
- **Teegi nimed** (`ui/i18n/et.ts`, `COMPONENT_LIBRARY` id järgi): `r_smd` „Takisti SMD“, `c_smd` „Kondensaator SMD“, `sot23` „SOT-23“, `soic` „SOIC“, `to220` „TO-220“, `hdr1` „Pinnirida 1×N“, `unknown` „Tundmatu komponent“ (alapealkiri „Kohandatud korpus“).
- **Otsing:** tõstutundetu (`et` lokaat), tühikutega eraldatud sõnad peavad kõik leiduma nimes või `kw`-s. Tühi päring näitab kõiki.
- **Korpuse parameetrid** valitud teegireal: `chip` suurus `0402`/`0603`/`0805`/`1206`; `sot23` jalad 3/5/6; `soic` jalad 8/14/16/20/24/28; `header1` jalad 1–40 ja samm 1,27/2/2,54; `area` laius ja kõrgus mm (> 0, kümnendkoma lubatud); `to220` parameetriteta. Vaikimisi on kirje `params`.
- **Paigutustööriist** (`ToolSpec` id `components.place`, rühm `draw`, klahvita): Teegi rea nupp **Paiguta** salvestab mooduli hoidlasse (`place-store.ts`) `{ mode: 'new'; entryId; params }` ja seab `toolId`. Liikumisel eelvaade `{ owner: 'components.place', data: { footprint, params, center } }`. Komponentide kere kiht joonistab selle katkendliku `--sel` kontuurina (`bodyOutline`). Klõps (< 3 px) kutsub `components.add(makePlacedComponent(ids, entry, params, world))`. Õnnestumisel valitakse uus komponent ja tööriist läheb tagasi `select`-ile; ebaõnnestumisel jääb tööriist alles ja Teek näitab `errors.ts` teadet. `Esc`, tööriista ja projekti vahetus kustutavad eelvaate ja hoidla oleku.
- **Paigutamata komponent:** rea nupp **Paiguta plaadile** avab korpuse valiku, kus on kõik teegi kirjed. Sobimatu kirje on keelatud põhjusega „Jalad ei sobi: komponendil {n}, korpusel {m}“ (või „Jalgade nimed ei sobi“, kui arv on sama). Sobivus: `footprintPinIds(footprint, params)` hulk võrdub komponendi jalgade `id`-de hulgaga; `area` sobib alati. Sobiva valiku järel läheb tööriist režiimi `{ mode: 'existing'; componentId; footprint; params }` ja klõps kutsub `components.placeOnBoard({ id, board: { footprint, params, center } })`. Jalgade `uid`-id säilivad. Proovitavad parameetrid: kirje `params` ning eelmises punktis loetletud jalaarvud.
- **Plaadil:** paigutatud komponendid tähise järgi (`localeCompare`, `numeric: true`), klõps valib komponendi.
- **Kontekstisektsioon „Korpus ja asend“** (`appliesTo: ['component']`, ainult paigutatud komponendil): korpuse nimi ja parameetrid (ainult lugemiseks), nurk kraadides, pool („Pealmine“/„Alumine“). Nupud: **Pööra +90°**, **Pööra −90°**, **Teisele poolele**, **Eemalda paigutus plaadilt** (`components.removeFromBoard`; komponent, jalad ja mõõtmised jäävad, valik jääb komponendile).
- **Mooduli klahvid:** `UiModule.keys?: KeySpec[]`, `KeySpec = { id: string; key: string; shift?: boolean; run(api: ToolApi, selection: Selection): boolean }`. `UiRegistry.keys()` koondab. Registreerimine kukub, kui sama `key`+`shift` on kahel kirjel või ühtib tööriista klahviga (`V`, `H` ja teised `ToolSpec.key`). `Canvas` saab propi `keys` ja käivitab need pärast aktiivse tööriista `onKey`-d samade kaitsetega (sisestusväli, dialoog, `Ctrl`/`Meta`). Komponendid: `R` → `components.rotate { deltaDeg: 90 }`, `Shift+R` → `-90`, `F` → `components.flipSide`, kõigile valitud paigutatud komponentidele (M1.1-s üks). Ilma paigutatud valikuta tagastab `run` `false`.
- **Tühjad olekud:** Plaadil: „Plaadil pole veel midagi. Ava **Teek** ja paiguta esimene komponent plaadile.“ Plaadile paigutamata: „Kõik komponendid on plaadil.“ Otsing: „Sellist korpust ei leitud. Proovi **Kohandatud**: sellele saad ise jalad lisada.“, kus „Kohandatud“ on nupp, mis tühjendab otsingu ja valib kirje `unknown`.
- **Tundmatu komponent:** `unknown` kirjest tuleb `kind: 'other'`, korpus `area`, tähis `X1`, jalgu pole, `identified: false`. Jalad lisatakse olemasoleva jalgade tabeliga; nende asukohad lõuendil tulevad M1.4-s.
- **Uue komponendi väärtus ja märgistus** on tühjad.
