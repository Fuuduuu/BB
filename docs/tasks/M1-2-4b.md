## Otsused ja liidesed
- **`ViewState.modules?: Record<string, unknown>`:**
  - `DEFAULT_VIEW_STATE.modules = {}`.
  - `parseViewState` säilitab kirje, kui see on objekt; muu väärtus annab `{}` ja ülejäänud vaade jääb kehtima. Moodul loeb oma pesa ise ja tolerantselt.
  - Vaate pood saab `modules` ja `setModuleView(id: string, value: unknown)`. `getView` ja `restore` kannavad `modules`-i edasi.
  - `use-workbench` salvestab vaate ka siis, kui muutub `modules`.
  - `save-coordinator` võrdleb ka `modules`-i (`JSON.stringify` võrdlus sobib, väärtused on väikesed). Ainult vaate muutus ei tõsta `rev`-i.
- **Foto vaate seaded** (`modules.photo`): `{ visible: boolean, opacity: number, contrast: number, gray: boolean }`.
  - Vaikimisi `{ visible: true, opacity: 1, contrast: 1, gray: false }`.
  - `readPhotoView(value: unknown)` parandab iga välja eraldi: `opacity` lõigatakse vahemikku 0,1…1 ja `contrast` vahemikku 0,5…2; vigane väli võtab vaikeväärtuse.
  - `PhotoLayer` rakendab seaded: `visible: false` → ei renderda; `opacity`; CSS `filter: contrast(c) grayscale(1|0)`.
- **Vasak pool** (fotomooduli `bottomBar` pesa, ainult aktiivse foto korral):
  - nupp „Peida foto“ / „Näita fotot“ (`aria-pressed`);
  - liugur „Läbipaistvus“ 10–100 %;
  - liugur „Kontrast“ 50–200 %;
  - lüliti „Hall“;
  - nupp „Pööra 90°“ → `photo.setTransform` päripäeva järgmise teisendusega;
  - nupp „Peegelda“ → `photo.setTransform` horisontaalselt peegeldatud teisendusega.

  Pööramine ja peegeldamine on dokumendikäsud: üks tagasivõetav samm ja `rev` tõuseb.
- **Teisenduste liitmine:** `rotateClockwise(t)` ja `mirrorHorizontal(t)` on puhtad funktsioonid fotomoodulis. Need on tuletatud samast 2×2 maatriksite tabelist, mida kasutab `stage.ts`: uus maatriks on ekraanioperatsioon korrutatud vana maatriksiga, tulemus on üks 8-st nimest.
- **Mõõtkava kiip** (fotomooduli pesa, ka fotota): „Kalibreerimata“, kui `scale.calibrated === false`, muidu „{pxPerMm} px/mm“ kahe kümnendkohaga ja komaga (nt „14,05 px/mm“). Selles kaardis ei ole see nupp.
- **Parem pool** (shell, alati nähtav töölaual):
  - nupud „Vähenda“ ja „Suurenda“ (suumi samm ×1,25 ümber vaate keskpunkti, piirid samad mis rattal) ja suumi protsent („100 %“);
  - nupp „Sobita“: Canvas mahutab teisendatud tööpinna (M1-2-4 positiivne stseen) nähtavasse alasse 5 % äärisega. Canvas teab oma mõõte, seega annab vaate pood selleks ainult päringu (`requestFit()` loendur, mida ei salvestata) ja Canvas täidab selle;
  - kursori asukoht „X 12,3 mm · Y 4,5 mm“ (üks kümnendkoht, maailm / `pxPerMm`). Lõuendilt väljas või ilma hiireta „X — · Y —“. Asukoha uuendus ei renderda kihte uuesti (eraldi väike pood või ref, kuni üks uuendus kaadris).
- **Arhitekti vastus ehitajale (2026-11-12): „Sobita“ sihiks on nähtav ala.** Kitsas vaates on omaduste paneel lõuendi peal, seega mahutatakse foto alasse, mida paneel ei kata. Tehnik vajutab „Sobita“, et näha kogu plaati. Paneeli all olev osa pole nähtav.
  - Canvas saab valikulise prop'i `fitInsets?: { left?: number; right?: number; top?: number; bottom?: number }` (px, vaikimisi 0). „Sobita“ arvestab neid, pan ja suum muidu mitte.
  - `Workbench` annab `right = contextWidth` ainult siis, kui kontekstipaneel on avatud **ja** ülekattena (kitsas vaade). Laias vaates on paneel lõuendi kõrval ja nihet pole vaja.
  - Kui vaba ala on liiga kitsas (laius < 200 px), sobita kogu SVG ala järgi.
  - Test: `fit_uses_area_not_covered_by_overlay_panel`.
- **„Valmis“ kaob:** `et.shell.ready`, selle `span` ja CSS eemaldatakse.
- **Tekstid:** shelli tekstid `ui/src/shell/i18n/et.ts`-is, foto tekstid fotomooduli `i18n/et.ts`-is. Numbrid kümnendkomaga.
