## Otsused ja liidesed
- **Generaatorid.** Iga prototüübi generaator tuleb BB-sse samade arvudega. Allikas on `01-footprints.js` ja arve ei ümardata ümber; kasuta `roundMm`.

  | BB `footprint` | Prototüübi allikas | Parameetrid |
  |---|---|---|
  | `chip` (olemas) | `gChip(CHIP)` | `size`: 7 suurust (domeenis juba olemas) |
  | `chip_tant` | `gChip(TANT, …polar)` | `case` A/B/C/D |
  | `chip_diode` | `gChip(DIO, …polar)` | `case`: SOD-323, SOD-123, SMA, SMB, SMC |
  | `el_smd` | `gElSmd` | `D` |
  | `axial` | `gAxial` | `pitch`, `bl`, `bd`, `band` (diood THT) |
  | `disc` | `gDisc` | `pitch` |
  | `radial` | `gRadial` | `D`, `pitch` |
  | `led_tht` | `gLedTht` | `D` |
  | `sot23` (olemas) | `gSot23` | `pins` |
  | `sot223`, `dpak`, `to92` | samanimelised | — |
  | `to220` (olemas) | `gTo220` | — |
  | `soic` (olemas) | `gSop` | `pins`, `body` |
  | `sop` | `gSop` (TSSOP/MSOP) | `pins`, `pitch` |
  | `dip` | `gDip` | `pins`, `row` |
  | `qfp`, `qfn` | `gQuad` | `pins`, `pitch`, `body` (0 = auto); `qfn` lisaks `ep` |
  | `header1` (olemas) | `gHdr1` | `pins`, `pitch` |
  | `header2` | `gHdr2` | `pins` (paare), `pitch` |
  | `jst` | `gJst` | `series`, `pins` |
  | `terminal` | `gTerm` | `pins`, `pitch` |
  | `usb_c`, `micro_usb`, `dc_jack` | samanimelised | — |
  | `xtal`, `xtal_smd`, `button`, `trimmer` | `gXtal`, `gXtalSmd`, `gBtn`, `gPot` | — |
  | `point` | `tp`, `via`, `pad`, `wire`, `hole` (read 217–221) | `type`, lisaks `shape`/`size` (padi) või `D` (ava) |
  | `area` (olemas) | — (BB „Tundmatu komponent“) | `w`, `h` |

  - Generaator, mis tagastab vigase parameetri korral `undefined`, järgib `soic.ts` mustrit (`defineFootprint`, `readNumber`).
  - QFN-i keskpadi `ep = jah` korral on lisajalg `4n + 1` nimega „EP“, nagu prototüübis.
  - Jala nimi (`P(…, name)`, näiteks `K`, `A`, `+`, `−`, `W`, `SW`) läheb paigutamisel jala nimeks, kui `makePlacedComponent` seda toetab. Kui ei toeta, jäta nimed ära ja kirjuta see üleandmisse.
- **Kere.** `body.w` ja `body.h` on prototüübi kere kujundite (`Rc`, `Ci`, `Pa` ja `bb`) piirkast.
  - `pin1` võetakse prototüübi `Dt(…)` märgist. Kui märki pole, siis `pin1` puudub.
  - Punktkomponentidel on keha 0 × 0. `bodyOutline` tagastab `[]`, kui `w ≤ 0` või `h ≤ 0`, nii et kere ei joonistata ega tabata; jala tabamus jääb.
- **Padjandi kuju.**
  - `PadGeom.shape` saab väärtuse `'oval'` (prototüübi `oval`).
  - `boardPads.shape` kannab selle edasi.
  - Joonisel on `oval` ristkülik, mille nurgaraadius on `min(hx, hy)`.
  - Tabamuses käsitletakse `oval`-i nagu `rect`-i.
  - Läbiva ava (`drill`) joonistamine jääb hilisemaks; `through` jääb `drill > 0` järgi.
- **Teegi kirjed (`COMPONENT_LIBRARY`).** Kõik 40 kirjet on prototüübi järjekorras.
  - Väljad: `id` on prototüübi `key`; `custom` asemel jääb `unknown`. Lisaks `kind`, `footprint`, vaikimisi `params`, `kw`, `category` ning `paramSpec`.
  - `kind` valitakse olemasolevast loendist, nii et tähise eesliide (`refs.ts`) vastab prototüübi `prefix`-ile.
    - Tantaal ja elektrolüüt on `capacitor_polarized`.
    - SOT-23, DPAK ja TO-92 on `npn`.
    - SOT-223 ja TO-220 on `regulator`.
    - Trimmer on `resistor` (BB-s R, prototüübis RV). Uut liiki ei lisata; kirjuta see üleandmisse.
    - Punktid on `testpoint`, `via`, `pad`, `wire_point` ja `hole`.
- **Parameetrite kirjeldus (`paramSpec`).** Kõvakodeeritud `footprintPinCounts` ja `headerPitches` asendab andmetel põhinev kirjeldus:

  ```ts
  type ParamSpec =
    | { key: string; label: string; choices: readonly (string | number)[] }
    | { key: string; label: string; min: number; max: number; step: number };
  ```

  - `Library.tsx` joonistab valikud ja arvuväljad kirjelduse järgi. Sildid on prototüübist (`Korpus`, `Jalgu`, `Samm`, …) ja asuvad `i18n/et.ts`-is.
  - `area` jääb erijuhuks (laius ja kõrgus).
  - `compatiblePlacement` loeb jalgade arvu valikud `paramSpec`-ist (võti `pins`), mitte enam `footprintPinCounts`-ist.
- **Kategooriad.** Teegi loend on rühmitatud prototüübi `CATS` järgi:
  - „Passiivsed“;
  - „Pooljuhid“;
  - „Mikroskeemid“;
  - „Konnektorid“;
  - „Muud“;
  - „Punktid plaadil“.

  Rühma pealkiri on 12 px. Otsing filtreerib kõigist rühmadest ja tühjad rühmad peidetakse.
- **Nimed.** `library.names` saab kõik 40 eestikeelset nime prototüübist. `unknown` jääb „Tundmatu komponent“.
