Sellest võetud dokumendi JSON läheb `releases/v0.1.0.document.json`. Rusti test avab **kõik** `tests/fixtures/v*.pcbk` failid ajutises koopias (`Storage::open`), dokument loetakse ja algfail jääb baithaaval samaks. TS test käib läbi **kõik** `releases/*.document.json`: `migrateDoc` → `BoardDocSchema.parse` → `validateDocument` õnnestuvad ning komponendid `R1` ja `U1` (jalg 3 nimi `FB`, jalg 8 `nc: true`) on alles. Reegel 03 §9-sse: iga väljalase lisab oma näidisfaili mõlemasse kausta.
- **Veakood `internal`:** `EngineError` saab `{ code: 'internal'; message: string }`. Engine'is lisa `CommandRejected extends Error { reason: string }` ja `reject(reason: string): never` (eksporditud `@pcbk/engine`-ist). `locked` teisendus: `CommandTargetNotFound` → `not_found`; `ZodError` → `validation` (issues); `CommandRejected` → `validation` ühe `custom` issue'ga, `message = reason` (praegune kuju, UI ei muutu); `engine_busy` → `validation` nagu praegu; **muu viga** → `internal` (`message` = vea tekst või `'unknown'`) ja kutse `opts.onInternalError?.(error, commandId)`.
- **Teisenda tahtlikud käsuvead** `throw new Error('<reason>')` → `reject('<reason>')`: `already_placed`, `component_not_placed`, `footprint_pins_mismatch`, `invalid_footprint`, `pin_not_active`, `same_probe_twice` ja `items.ts`-i oma. Mootori sisekontrollid (`invalid_document_value`, `cyclic_*`, `revision_overflow`, `async_command` jms) jäävad tavaliseks `Error`-iks, sest need on programmivead.
- **`createEngine` opts** saab `onInternalError?(error: unknown, commandId: string): void`. Mõlema äpi `runtime.ts` logib `console.error('[engine] internal', commandId, error)`.
- **UI tekst** `internal` korral (komponentide `errors.ts` ja mõõtmiste `commandError`): „Sisemine viga, muudatust ei tehtud. Salvesta diagnostika ja anna veast teada.“
- **Eemalda** kasutamata `EngineModule.migrations` (`types.ts`); migratsioonid elavad ainult domeenis (`MIGRATIONS`).
- **ESLint** ignoreerib `.claude/worktrees/**` (teise seansi tööpuu põhikaustas murdis `pnpm check`-i).
