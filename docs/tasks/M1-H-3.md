- **Domeeni alamteed** (`packages/domain/package.json` `exports`, juurtee `"."` jääb ja ekspordib kõike nagu praegu):
  `./model` → `src/model/index.ts` (uus, koondab `model/*`), `./components` → `src/components/index.ts` (uus: `refs`, `pins`), `./footprints` (olemas), `./geometry` (olemas), `./measure` ja `./measure/reading` (olemas), `./migrations` → `src/migrations/index.ts`, `./ids` → `src/ids.ts`, `./doc` → `src/doc.ts`, `./constants` → `src/constants.ts`. Sõltuvusreegel (UI tohib domeenist käituskoodi võtta ainult `geometry/`, `footprints/` ja `measure/reading.ts` failidest) ei muutu ja peab ka uute alamteede korral kehtima.
- **API kokkuvõte alamtee kaupa:** `api-digest.mjs` loeb domeeni sisenemispunktid `packages/domain/package.json` `exports`-ist (välja arvatud `"."`) ja kirjutab faili `docs/api/domain-<alamtee>.md` (`/` → `-`, nt `domain-measure-reading.md`). `docs/api/domain.md` jääb lühikeseks sisukorraks: alamteede loetelu koos linkidega, mitte deklaratsioonid. `pnpm api:check` kontrollib kõiki faile; vananenud `domain*.md` failid kustutatakse. Iga domeeni API fail jääb alla 400 rea (hoiatus `domain.md` 712 rida kaob).
- **Katvus (kasutaja kinnitas 2026-11-11):** lisa arendussõltuvus `@vitest/coverage-v8` täpselt versioonil `5.1.0` (sama mis `vitest`), lukufail uueneb. `vitest.config.ts`: `coverage.provider = 'v8'`, `include: ['packages/domain/src/**/*.ts']`, `exclude: ['**/*.test.ts', '**/__fixtures__/**', '**/index.ts']`, `thresholds: { lines: 90, functions: 90, branches: 85, statements: 90 }`. Juurskript `coverage`: `vitest run --coverage`. CI `checks` töös lisandub samm `pnpm.cmd coverage` pärast `pnpm.cmd check`. Kui praegune katvus jääb lävest alla, lisa puuduvad domeenitestid (mitte läve langetamine) ja nimeta üleandmises, mida lisasid.
- Kui `@vitest/coverage-v8@5.1.0` paigaldamine ebaõnnestub (võrk, versioon), peatu ja kirjuta arhitektile; ära vali teist versiooni.
