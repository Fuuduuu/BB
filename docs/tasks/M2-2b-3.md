## Otsused ja liidesed
1. **Kuju on korpuse definitsioonis, mitte geomeetrias.**
   - Plaan pakkus välja `FootprintGeom.body.shape`. Kaitsetest võrdleb aga 206 korpuse geomeetria JSON-i algjoonega, nii et uus väli rikuks selle.
   - `types.ts`:
     - `export type BodyShape = 'rect' | 'circle' | 'oval' | 'd'`;
     - `export type BodyFlat = '-x' | '+x' | '-y' | '+y'`;
     - `export interface BodyShapeSpec { shape: BodyShape; flat?: BodyFlat }`.
   - `FootprintDef` saab välja `bodyShape?: BodyShapeSpec`. `defineFootprint` saab viienda valikulise argumendi `bodyShape`.
   - `footprints/index.ts`: `footprintBodyShape(key: string): BodyShapeSpec` tagastab definitsiooni `bodyShape` või `{ shape: 'rect' }`.
2. **Üks kontuurifunktsioon.**
   - `bodyLocalOutline(body: FootprintGeom['body'], spec: BodyShapeSpec): Vec2[]` annab kontuuri korpuse millimeetrites, keskpunkt (0, 0). Tühi massiiv, kui `w ≤ 0` või `h ≤ 0`.
   - `rect`: neli nurka praeguses järjekorras: (−w/2, −h/2), (w/2, −h/2), (w/2, h/2), (−w/2, h/2).
   - `circle`: ellips raadiustega w/2 ja h/2, 48 punkti nurkadel k·360°/48. Esimene punkt on (w/2, 0).
   - `oval` (staadion):
     - pikk telg on suurem mõõt, raadius r = väiksem mõõt / 2;
     - kahe poolringi keskpunktid on pikal teljel kaugusel ±(pikk/2 − r);
     - kumbki poolring on 25 punktiga, otspunktid kaasa arvatud, kokku 50;
     - sirged küljed tekivad poolringide vahele.
   - `d` (lame küljega ring):
     - Lameda telje järgi (`±x` → x, `±y` → y) on L = pool kasti mõõtu sellel teljel ja R = pool risti-mõõtu.
     - Ringi kese on lameda teljel s·(R − L), kus s = +1 `+`-poolele ja −1 `−`-poolele, ning teisel teljel 0. Nii puudutab kaar vastasserva.
     - Lame külg on sirge kasti serval s·L.
     - Kaar läheb ühest lõikepunktist teiseni üle vastaskülje 48 võrdse lõiguga (49 punkti). Hulknurk suletakse lameda küljega.
     - Kui sirge ringi ei lõika, on tulemus ring nagu `circle`.
   - `bodyOutline(placement, pxPerMm)` = `bodyLocalOutline(geometry.body, footprintBodyShape(placement.footprint))`, mis teisendatakse `padToBoard`-iga. Nii järgivad uut kuju joonistus, tabamus, hõljumine, siltide takistused ja raamvalik ilma eraldi muudatuseta.
   - Kohalik kontuur puhverdatakse mooduli `Map`-is võtmega `${shape}|${flat}|${w}|${h}`, et 300 komponendi renderdus ei arvutaks trigonomeetriat korduvalt.
3. **Korpused (O4).**
   - `radial`, `el_smd` → `{ shape: 'circle' }`.
   - `disc`, `xtal` → `{ shape: 'oval' }`.
   - `led_tht` → `{ shape: 'd', flat: '-x' }`, sest `K` jalg on x = −1,27.
   - `to92` → `{ shape: 'd', flat: '+y' }`, sest lame esikülg on jalgade rea all.
   - Kõik teised jäävad `rect`-iks.
4. **Teegi eelvaade sama funktsiooniga.**
   - `FootprintPreview` saab propi `footprint: string`; `silhouette` teab kirje `footprint`-i.
   - `rect` joonistub nagu praegu `<rect>`-ina. Muud kujud joonistuvad `<polygon data-body-shape="circle|oval|d">`-ina, punktid tulevad `bodyLocalOutline`-ist ning täidis ja joon on samad mis praegusel ristkülikul.
   - `viewBox` ei muutu, sest kontuur jääb kasti `w × h` sisse.
5. **Nimed (O3).**
   - `library.names.c_disc` ja `footprints.disc` = „Keraamiline kondensaator THT“.
   - `library.names.c_smd` = „Keraamiline kondensaator SMD“.
   - `discFootprint`-i definitsiooni nimi = „Keraamiline kondensaator THT“.
   - Elektrolüütide nimed jäävad.
